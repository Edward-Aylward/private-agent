# Private Agent

Private Agent is Edward Aylward's rebranded AI agent runtime.

This repository contains the local agent foundation that will be integrated into the generalized AI automation product.

## Brand status

- Primary logo: full three-shield crest artwork
- README/logo asset: `assets/banner.png`
- Website logo asset: `website/static/img/logo.png`
- Website banner/social image: `website/static/img/Private-agent-banner.png`

## Current product direction

Private Agent will serve as the customer-side runtime for a downloadable AI automation platform. The broader product journey includes:

1. customer purchase or product-key activation
2. secure setup-link onboarding
3. voice-first interview
4. custom automation blueprint generation
5. agentic AI team creation
6. local Private Agent installation/configuration
7. customer-owned or hosted inference configuration
